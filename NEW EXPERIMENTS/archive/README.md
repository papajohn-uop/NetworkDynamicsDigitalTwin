# Archive Directory

This directory stores legacy and prototype scripts that have been superseded by production analysis scripts.

## Contents

- `analyze_sweeps.py`:
  - **Status**: Superseded & Deprecated.
  - **Original Purpose**: Early prototype tool created to analyze Experiment 3 (TCP CUBIC parametric sweeps only).
  - **Superseded By**: [`analyze_impairments_results.py`](../analyze_impairments_results.py), which performs comprehensive analysis of both Experiment 3 (TCP CUBIC) and Experiment 4 (TCP Reno), parametric/non-parametric statistics, head-to-head comparative metrics (Tables 1–4), and generates publication-grade figures (Figures 1–12 in `plots/impairments/`).
